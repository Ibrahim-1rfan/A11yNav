## Chrome
1. Select Profile, your picture or name at the top right of the window.
2. Choose another profile to switch to it, or select Add Chrome profile to make a new one.
3. To change a profile's name, photo or colour, select Profile, then Manage Chrome profiles.

## Edge
1. Select the Profile icon in the upper-right corner of the window.
2. Choose the profile you want to use; Edge opens it in a new window. Or select Set up a new profile.
3. To browse without saving history, select the Profile icon, then Browse as guest.
