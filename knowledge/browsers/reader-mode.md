## Edge
1. Open the article you want to read.
2. Press F9 to enter or leave Reading mode (called Immersive Reader in older versions). It works only on supported pages.
3. You can also select the Reading mode button in the address bar. To show that button, open Settings and more, then Settings, Appearance, Toolbar, and turn on Reading mode.
4. To read only part of a page, select the text, right-click it and choose Open selection in Reading mode.
5. To change the look, select the Settings icon in the Reading mode toolbar, choose Appearance settings, then pick a Font, Font size, Column width and Theme.

## Chrome
1. Open the page you want to read.
2. Right-click the page and select Open in reading mode. You can also select Reading mode in the address bar, or select More, then More tools, then Reading mode.
3. In reading mode use Increase or Decrease to change the text size, and Reset to go back.
4. Use Color theme, Font, Line height and Letter spacing to make the text more comfortable.
5. To keep reading mode on the toolbar, select Settings and then Pin reading mode.

## Firefox
1. Open the article you want to read.
2. Press F9 to turn Reader View on or off. You can also click the Reader View icon in the address bar when it appears.
3. Use the Text button on the left to change Text Size with minus and plus, the font, content width and line spacing. Advanced options set character and word spacing.
4. Use Theme to choose Light, Dark, Sepia, Contrast or Gray backgrounds, or make your own.
5. To leave Reader View, click the cross button or the Reader View icon again.
