## Chrome
1. Select Extensions, to the right of the address bar, to see your extensions.
2. To manage them, select More (the three dots at the top right), then Extensions, then Manage extensions.
3. To add one, open the Chrome Web Store, find the extension and select Add to Chrome.

## Edge
1. Select Extensions, to the right of the address bar, to see your extensions.
2. To turn one off, select Manage extensions in that list and use the switch next to it.
3. To add one, select Get Extensions for Microsoft Edge, find the extension and select Get.
