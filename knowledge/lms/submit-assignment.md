## LMS
1. Open {course} from the course tabs at the top.
2. Select Assignments in the left menu.
3. Select the assignment you want to submit. The list shows each one's Status and Due Date.
4. Read the Instructions, then type your answer in the Assignment Text box, or attach your file with Select a file from computer if the assignment allows it.
5. When you're done, select Proceed at the bottom of the page. To finish later instead, select Save Draft. A draft is not submitted.
6. On the next page, select Submit to hand it in.
