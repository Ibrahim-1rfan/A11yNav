## LMS
1. Select the Sites button, the grid of nine squares at the top right of the LMS page.
2. Find the course in the list. Type part of its name in Filter sites to find it faster.
3. Select the star next to the course to add it to the top bar. Select it again to remove it.
4. Select Reload in the message that appears to see your updated top bar. New courses are added for you automatically.
